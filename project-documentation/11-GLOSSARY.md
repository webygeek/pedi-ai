# Glossary

Complete reference of medical, technical, and business terms used in Pedi-Ai.

---

## 📋 Medical Terms

### Developmental Terms

| Term | Definition |
|------|------------|
| **ABC** | Antecedent-Behavior-Consequence — Framework for understanding behavior |
| **Adaptive Behavior** | Skills needed for daily life (communication, self-care) |
| **Ataxia** | Lack of muscle coordination during voluntary movements |
| **Cerebral Palsy** | Group of disorders affecting movement and posture |
| **Cognitive Development** | How children think, explore, and solve problems |
| **Developmental Milestone** | Skills or behaviors most children can do by a certain age |
| **Dysarthria** | Speech difficulty due to muscle control problems |
| **Fine Motor Skills** | Small muscle movements (grasping, drawing) |
| **Gross Motor Skills** | Large muscle movements (walking, jumping) |
| **Hypotonia** | Low muscle tone, muscles appear floppy |
| **Joint Attention** | Shared focus on an object between two people |
| **Milestone Regression** | Loss of previously achieved skills |
| **Motor Planning** | Ability to plan and execute movements |
| **Plagiocephaly** | Flat spots on a baby's head |
| **Primitive Reflexes** | Reflexes present at birth that typically disappear over time |
| **Proprioception** | Awareness of body position in space |
| **Social-Emotional Development** | Skills for interacting with others and understanding feelings |

### Growth & Nutrition Terms

| Term | Definition |
|------|------------|
| **BMI** | Body Mass Index — Measure of body fat based on height and weight |
| **Body Composition** | Proportions of fat, muscle, and bone in the body |
| **Catch-Up Growth** | Accelerated growth after a period of slower growth |
| **Failure to Thrive** | Inadequate growth compared to expected patterns |
| **Growth Hormone** | Hormone that stimulates growth and cell reproduction |
| **Growth Velocity** | Rate of growth over a specific time period |
| **Head Circumference** | Measurement around the largest part of the head |
| **Length** | Measurement of a lying-down child (under 2 years) |
| **Height** | Standing measurement (over 2 years) |
| **Macrocephaly** | Abnormally large head |
| **Microcephaly** | Abnormally small head |
| **Percentile** | Position relative to 100 children of the same age/sex |
| **Recumbent Length** | Measurement while lying down |
| **WHO Growth Standards** | International growth references developed by WHO |

### Chronic Conditions

| Term | Definition |
|------|------------|
| **Acute** | Sudden onset, short duration |
| **ADHD** | Attention-Deficit/Hyperactivity Disorder |
| **Allergen** | Substance that triggers allergic reactions |
| **Anaphylaxis** | Severe, life-threatening allergic reaction |
| **Atopic Dermatitis** | Chronic inflammatory skin condition (eczema) |
| **Autoimmune** | Condition where immune system attacks the body |
| **Biologics** | Medications made from living organisms |
| **Bronchodilator** | Medication that opens airways |
| **Chronic** | Long-lasting, persistent condition |
| **CGM** | Continuous Glucose Monitor — device tracking blood sugar |
| **Co-morbidity** | Presence of two or more conditions |
| **DPI** | Dry Powder Inhaler |
| **Eczema** | Skin condition causing itchiness and inflammation |
| **Eosinophils** | White blood cells involved in allergic reactions |
| **Epinephrine** | Medication for severe allergic reactions |
| **Flare** | Period when symptoms worsen |
| **GFR** | Glomerular Filtration Rate — kidney function measure |
| **HbA1c** | Hemoglobin A1c — measure of average blood sugar over 2-3 months |
| **Hydroxyzine** | Antihistamine for itching and anxiety |
| **I:C Ratio** | Insulin-to-Carbohydrate ratio |
| **Inhaler** | Device delivering medication to lungs |
| **Insulin** | Hormone regulating blood sugar |
| **Long-Term Control** | Medications for ongoing condition management |
| **MDI** | Metered-Dose Inhaler |
| **Nebulizer** | Machine converting liquid medication to mist |
| **Peak Flow** | Maximum speed of exhaled breath |
| **Prodrome** | Early symptoms indicating disease onset |
| **Quick-Relief** | Medications for immediate symptom relief |
| **Remission** | Period when symptoms decrease or disappear |
| **Spirometry** | Lung function test |
| **Status Asthmaticus** | Severe, persistent asthma attack |
| **Trigger** | Factor that worsens symptoms |
| **Type 1 Diabetes** | Autoimmune condition where pancreas doesn't produce insulin |
| **Zone System** | Asthma classification (Green/Yellow/Red) |

| **GAD-7** | Generalized Anxiety Disorder 7-item scale |
| **Mood Disorder** | Condition affecting emotional state |

| **Positive Reinforcement** | Encouraging behavior by rewarding |
| **SCARED** | Screen for Child Anxiety Related Disorders |
| **Selective Mutism** | Inability to speak in certain situations |
| **Sensory Processing** | Brain's interpretation of sensory information |
| **Separation Anxiety** | Fear of being away from caregivers |
| **Social Anxiety** | Fear of social situations |
| **Time-Out** | Strategy for removing attention after misbehavior |
